Overview
Carverse is a full-stack car marketplace platform that allows users to:
•	Browse available car listings.
•	Create and manage car entries (planned).
•	Search and filter cars using an intuitive interface.
•	Potential AI features to generate car descriptions (if included).
Built with modern technologies suitable for production, scalable deployments, and rapid iteration.

Features
•	Next.js (App Router)
•	React & Tailwind CSSR
•	Responsive design for mobile & desktop
•	SEO-ready pages
•	AI-enhanced capabilities (future support)
•	Deployment optimized for Vercel
